    Development Notes

    • Blueprint match. Items B1 to B8 match the Set B rows of the grade 5 test blueprint exactly: standards, item types, DOK, difficulty, and points. Together with The Praline Pot, the two sets form the full 16-item, 20-point form.
    • Why this passage. It pairs by topic with the literary set (Lise’s grainy first batch is crystallization in action) without sharing any tested content, so no item on one set helps a student answer an item on the other.
    • Passage revision for level. The first draft measured about 1080L. I shortened sentences, defined terms in separate sentences, and replaced a few multisyllabic words until the passage measured within the grades 4 to 5 band, keeping the science intact.
    • Distractor design. Distractors use accurate details that answer a different question, reverse a cause and effect, or confuse one candy with another, so wrong answers point to specific misunderstandings.
    • Bias and sensitivity review. Candy making is presented as a widely shared activity; no item requires cooking experience, and every answer is supported by the article.
