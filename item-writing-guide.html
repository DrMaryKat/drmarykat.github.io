ELA Item Writing Guide

Rules for writing passage-based items for large-scale K-12 assessment

Dr. Mary K Boudreaux, EdD
Item writer training, one-page reference
The one rule behind every rule: a student should get an item right only because they have the skill the standard describes, and wrong only because they do not. Anything else that affects the answer (reading load in the stem, a clue in the options, background knowledge, a tricky format) is error to remove.

1. Alignment

  1. One item, one standard. Name the standard before you write, and test its main demand, not a side skill.
  2. Match the cognitive demand. Set the target DOK first; a "theme" item that only asks students to recall an event is DOK 1, not DOK 3.
  3. The passage must carry the answer. Every key is defensible with text evidence; no outside knowledge required.
  4. Spread items across the passage, and do not let one item give away the answer to another.

2. Stems

  1. Ask a complete question. A student should be able to answer before reading the options.
  2. Point to the text. Cite paragraph numbers or quote the line being tested.
  3. Keep the language below the passage level. The stem is never the hard part.
  4. Avoid negatives (NOT, EXCEPT). If one is unavoidable, use bold capitals.
  5. Use "best" honestly. If options are partly correct, the key must be clearly strongest.

3. Keys and distractors

  1. One clearly correct key, confirmed by at least one other reviewer.
  2. Every distractor names a real misreading: a true detail that does not answer the question, a partial understanding, a reversal, or an overgeneralization. Write the rationale as you write the option.
  3. Make options parallel in length, grammar, and specificity; the longest option should not be the key.
  4. No "all of the above," "none of the above," or joke options.
  5. Balance key positions across a form (roughly equal A, B, C, D).

4. Two-part and technology-enhanced items

  1. Two-part (EBSR): Part A tests the inference; Part B asks for the evidence for Part A. Part B options must all be real quotations.
  2. The format must add measurement, not decoration. Use drag-and-drop or hot text only when it tests the skill better than multiple choice.
  3. State the scoring rule up front (all-or-nothing or partial credit) and keep directions to one clear sentence.
  4. Build a keyboard path for every interaction.

5. Constructed response and rubrics

  1. The prompt names the task and the evidence required ("Use two details from the story").
  2. Write the rubric with the prompt, one score point per meaningful difference in quality.
  3. Describe what is present at each level, not only what is missing.
  4. List acceptable responses and draft anchor papers at every score point before field testing.

6. Fairness, accessibility, and AI

  1. Bias and sensitivity: no stereotypes, no content that requires a particular culture, region, or income to understand; represent communities from the inside and with accuracy.
  2. Accessibility: plain syntax, no idioms in stems, readable formats, and items that work with read-aloud and screen readers.
  3. AI is a drafting and review partner, not the author. Verify every key, rationale, quotation, and alignment claim against the passage and standard; record where AI was used.

Revision example

Before

Lise is NOT shown as which of the following?
A. impatient   B. eager   C. a girl who learns to listen to Mon-mon and finally makes the pralines correctly   D. all of the above

Negative stem, no text reference, a key that stands out by length, and "all of the above."

After

Which word best describes Lise in paragraphs 6 to 8?
A. careful   B. impatient   C. confused   D. lonely

Positive stem, a clear text range, parallel one-word options, and each distractor tied to a misreading (A reverses her behavior; C and D are not supported).

Before you submit, ask: Is it aligned to one standard at the target DOK? Can the key be proved with the passage alone? Does every distractor have a written rationale? Would a strong reader pick the key and a struggling reader find each distractor tempting for a real reason? Is it free of bias, clues, and unnecessary reading load?
